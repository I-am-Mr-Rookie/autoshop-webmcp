What makes it trustworthy

Small surface. Sharp edges.

Every feature exists to make the authority boundary legible within seconds — to a judge, a buyer, a seller, or the agent itself.

Role-scoped WebMCP tools

Three buyer tools and four seller tools, each with a strict input schema. Seller tools are registered only after sign-in and removed on logout, expiry, or leaving the page.

Ask or Auto scope

Ask keeps cart changes human-driven. Auto lets the agent browse and change the cart. Neither mode can submit until the buyer visibly confirms the exact order.

Visible buyer confirmation

Confirmation mints a one-time token bound to the exact cart version. Change the cart and authorization is cancelled; no order can be submitted until the buyer confirms again.

Numerical seller mandate

Items per order, total, discount, and minimum remaining stock are versioned limits. Orders that fit are eligible for agent acceptance; the rest are not.

Exceptional approval, once

An out-of-mandate action becomes a pending item. A human reviews the exact action ID, ticks the confirmation, and commits it exactly once with an idempotency key.

Immutable receipts, honest data

Every commit changes synthetic stock and issues a receipt that cannot be edited. Buyer-authored text is rendered as text, never as markup, and never authorizes anything.

Tool contracts

Seven tools. Nothing hidden.

What an agent connected through WebMCP can see on each page. Read-only tools never change state; mutating tools are marked and bounded.

/buyer3 tools · always registered

browse_products
Find up to 8 parts by an optional 80-character query. Read-only.
manage_cart
Add, set, or remove one bounded quantity. Changes cart state only.
submit_order
Submit one visibly confirmed order; private authorization never enters the tool input.
Seller tools are unavailable on this page.

/seller4 tools · after sign-in only

get_mandate
Read the current numerical mandate. Read-only.
list_orders
Read up to 5 order summaries. Buyer content is flagged untrusted.
accept_order
Accept a bounded quantity with an idempotency key — or get APPROVAL_REQUIRED.
commit_action
Commit one visibly approved action; private authorization never enters the tool input.
Removed on logout, session expiry, or leaving the page.
